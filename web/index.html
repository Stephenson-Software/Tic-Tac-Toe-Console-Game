Tic Tac Toe

The original Java console game, unchanged, running in your browser. You are X and move first.

Loading Java (the first visit downloads the runtime, which can take a little while)...

A move is a column letter and a row number: a1 is the top-left space, b2 the center, c3 the bottom-right.

Runs in your browser with CheerpJ (Leaning Technologies).
